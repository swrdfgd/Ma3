Information and communication theory, circuits

Mathematical foundations of entropy, channel capacity, error-correcting codes, cryptography, and switching circuit theory.

General reference works

Handbooks, foundational monographs, encyclopedias, and bibliographies pertaining to information and communication theory.

A Mathematical Theory of Communication (C. E. Shannon) ↗ Foundational Paper

Claude Shannon's seminal 1948 Bell System Technical Journal monograph establishing source coding, channel capacity, and information entropy.

Information Theory, Inference, and Learning Algorithms ↗ Textbook / Reference

David J. C. MacKay's comprehensive reference covering Shannon entropy, noisy-channel coding, error-correcting codes, and Bayesian inference.

Encyclopedia of Mathematics: Information Theory ↗ Encyclopedia

Peer-reviewed mathematical reference entries curated by the European Mathematical Society covering coding theory, entropy measures, and algebraic structures.

IEEE Information Theory Society Publications & Archives ↗ Bibliography / Society

Central portal for the IEEE Transactions on Information Theory, newsletters, bibliographies, and curated lecture notes across communication theory.

Table of Bounds on Linear Codes (Andries Brouwer / CodeTables) ↗ Tables / Reference

Standard reference tables listing upper and lower bounds on minimum distances for linear error-correcting codes over finite fields.

Handbook of Applied Cryptography ↗ Handbook

Comprehensive reference work by Menezes, van Oorschot, and Vanstone detailing mathematical foundations, protocols, and algorithms in cryptography.

Software, source code, etc.

Open-source libraries and computer algebra systems for entropy computation, coding theory, signal processing, and circuit design.

dit (Discrete Information Theory) ↗ Python

Python package for discrete information theory supporting Shannon entropy, mutual information, total correlation, and multivariate information decompositions.

SageMath Coding Theory Module ↗ Python / Cython

Extensive suite for constructing, decoding, and analyzing linear codes, cyclic codes, Goppa codes, and algebraic-geometric codes over finite fields.

GUAVA (GAP Package) ↗ GAP

Computer algebra package for computing with error-correcting codes, weight enumerators, automorphism groups, and covering radii.

GNU Radio ↗ C++ / Python

Free and open-source software development toolkit providing signal processing blocks to implement software-defined radios and communication systems.
