Relativity and gravitational theory

Mathematical foundations of special and general relativity, gravitational fields, and relativistic cosmology.

Software, source code, etc.

Open-source tools, symbolic tensor algebra packages, and numerical relativity frameworks for problems pertaining to relativity and gravitational theory.

SageManifolds ↗ Python / SageMath

Open-source package integrated into SageMath for symbolic differential geometry, tensor calculus on smooth manifolds, curvature computations, and exact solutions in general relativity.

Cadabra ↗ C++ / Python

Field-theory motivated computer algebra system designed for the manipulation and simplification of tensorial expressions with multi-term symmetries and differential forms.

xAct ↗ Wolfram Language

Suite of packages for symbolic tensor computer algebra, supporting both abstract index manipulation and component-based calculations in general relativity and perturbation theory.

EinsteinPy ↗ Python

Open-source Python library providing symbolic tensor manipulations, geodesic integration, metric computations, and visualization utilities for general relativity.

Einstein Toolkit ↗ C / C++ / Fortran

Community-driven open-source platform of core computational modules for simulating black holes, neutron stars, and relativistic astrophysics built on the Cactus framework.

SpECTRE ↗ C++

Open-source code for multi-scale, multi-physics problems in relativistic astrophysics and gravitational-wave source modeling using discontinuous Galerkin methods.
